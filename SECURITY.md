# Security Policy

## Reporting a vulnerability

Do not open a public issue containing an exploitable vulnerability or sensitive data. Use GitHub's **Private vulnerability reporting** feature on the repository's **Security** tab when available. Otherwise, contact the maintainers through a private channel before publicly disclosing the issue.

Include a description of the issue, reproduction steps, and its potential impact. Do not include Unreal logs or private project files.

## Scope

UE Logger listens on the local interface `127.0.0.1` and processes logs received from Unreal projects configured by the user. Vulnerability reports must not contain sensitive logs, file paths, or project identifiers.
